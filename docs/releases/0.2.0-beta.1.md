# HeroV Browser 0.2.0-beta.1

Date: 2026-10-22 · Tag: `v0.2.0-beta.1` · Channel: **test (beta)**, Windows x64 · Previous: `v0.1.0-camoufox.1`
From this release HeroV uses Semantic Versioning and shows its own version; see `docs/releasing.md`.

## What is new
- **You can see which build you run.** `v0.2.0-beta.1` under the logo in the rail (amber = test build), in the title bar and the tray tooltip. Click it for **Settings → About**: version, channel, build date, commit, an update check and **Copy build info** (one line to paste into a bug report).
- **New logo** everywhere: app icon, installer, taskbar, rail and favicon.
- **Faster Camoufox install**: the 1.3 GB engine downloads over eight connections (measured about nine times faster than one on this network) and continues after an interruption; unpacking uses several threads.

## Fixed
- **"Configuration Error" when starting a Camoufox profile** after the engine had been reinstalled while a profile was open. A reinstall now swaps folders all or nothing; an engine folder that lost a file shows as not installed, with the Install button back.
- "What's new" no longer opens on the engine's unrelated notes after updating HeroV.

## Upgrade notes
- Install over the previous version; no data migration. Profiles, proxies and settings are untouched.
- The version number goes from `2.0.3` (inherited) to `0.2.0-beta.1`. This is expected: `2.0.3` was the upstream launcher's number. The engine feed still receives `2.0.3` as the compatibility number, so the Chrome engine install is not affected.
- Test builds are offered newer test builds and stable releases; stable builds are offered stable releases only.

## Known issues
- Phone profiles: scanbrowser.net flags "Software"; CreepJS flags the pixel ratio and the WebGL parameters (no phone WebGL recording yet).
- Camoufox profiles: HTTPS-type proxies, extensions, bookmarks, cookie files and automation are Chrome-only for now.
- The installer is not signed: SmartScreen warns (More info → Run anyway).
