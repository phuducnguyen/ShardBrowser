# HeroV Browser 0.1.0-ui.1 — new interface

Date: 2026-10-19 · Tag: `v0.1.0-ui.1` · Type: interface release (first part of 0.1.0 "Foundation" in `plans/261019-herov-gap-roadmap/release-plan.md`)
The application's internal version number stays **2.0.3**: the runtime download check compares the launcher version with a minimum the engine feed publishes, so lowering it could block the first-run engine install. It moves when the engine feed and update channel are HeroV's own.

## What is new
- **New interface.** HeroV brand, rail navigation, light and dark themes. Windows ported to the new frame: Profiles, New/Edit profile, Proxies (with the Get proxies sheet), Fingerprints, Extensions, Bookmarks, Trash, Settings, Patch log, and the dialogs, first-run screen and star prompt around them.
- **Create profile, device first.** Engine, OS (Windows, Android, macOS, Linux), brand or GPU-maker filter, device, **OS version** (Android 12–16, Windows 10 and Windows 11 21H2–25H2), a Random device button, and a "What sites will see" card that lists the fixed identity. Camoufox and iOS are shown as unavailable with the reason.
- **Settings → Profile defaults.** Choose what every new profile starts from: OS, random device inside a filter or a pinned device, protections (canvas, WebGL image, audio, client rects, fonts, sensors), WebRTC, language and time zone. Saved in its own file, `profile-defaults.json`; a new backend command pair reads and writes it.
- **Tiếng Việt.** Vietnamese added (848 of 1573 strings). The Automation block palette, traffic panel and ProxyShard screens still show English where no Vietnamese exists.
- **Friendly device names.** Android devices read as `Brand Model`, Windows devices as `GPU · resolution`.
- **Tools.** `npm run check:fingerprints` (consistency check of the library) and `node scripts/creep-check.mjs` (real engine against CreepJS).

## Upgrade notes
- No data migration. Profiles, proxies, settings and the fingerprint library are untouched.
- Profile defaults from a pre-release build kept in local storage move to the new file on first start.

## Known issues
- **Android fingerprints are flagged by CreepJS** (`suspicious gpu` and `suspicious capabilities`, 50 of 50 entries): their WebGL parameter sets are not those of a known real device. Windows entries tested (3 of 3) are clean. Details and the plan to fix this: `docs/references/creepjs-findings.md`. Treat Android profiles as experimental.
- Automation, the traffic panel, the live view and the sync panel still use the previous look. ProxyShard is reachable only through the Get proxies sheet and is not part of this release's scope.
- The star prompt and the patch-log star lock still point at the repository; remove them when the repository becomes private.
- No installer or signing yet (0.1.0 proper).
- The Rust unit tests of the new module run in an isolated crate: the Tauri test binary does not start on Windows here (`STATUS_ENTRYPOINT_NOT_FOUND`).
