# HeroV Browser 0.1.0-camoufox.1 — second engine and phones

Date: 2026-10-21 · Tag: `v0.1.0-camoufox.1` · Type: pre-release (Windows x64) · Previous: `v0.1.0-ui.1`
The application's internal version number stays **2.0.3** for the reason given in the previous notes (the engine feed compares it with a minimum).

## What is new
- **Camoufox, a second browser engine (Firefox).** Install it from Settings → Browser (pinned `v158.0-beta.40`, 1.3 GB, checked against a SHA-256). Choose the engine when creating a profile; Chrome and Camoufox profiles run side by side, each with its own data folder.
  - Devices recorded from real Firefox for Windows, macOS and Linux; per-profile audio seed and font base; speech voices.
  - **WebGL masked** with recorded device identities (vendor, renderer, parameters, extensions, shader precisions): pixelscan reports "consistent", and scanbrowser.net reports browser, software, hardware and network all normal on a Windows profile.
  - **Proxies** (SOCKS5 and HTTP with login) through a local relay; names resolved by the proxy; no fallback to your own connection; time zone, language, position and WebRTC address follow the proxy's country (or your own address when there is no proxy).
  - Start, stop and the running state work as for Chrome profiles.
- **Android phones on Camoufox (experimental).** 114 phones: 12 named models and 102 built from real-browser statistics (Apify fingerprint-suite data), noise removed and every phone a consistent set of screen, pixel ratio, graphics chip and Android version.
  - Create profile → Camoufox → Android: filters for segment (flagship, mid-range, entry-level) and GPU family (Adreno, Mali, PowerVR) with counts; a random phone is chosen for you; Random device never repeats; the Android version list holds only versions that class of phone could run. Every automatic change is announced in a toast.
  - Firefox-for-Android user agent and platform (`Linux armv81`), 5 touch points, touch events, phone-sized window whose width equals the screen, overlay-style scrollbars, phone font list, no desktop speech voices.
- **Interface.** Collapsible navigation rail; deeper button colours; visible edges between regions; Bind proxy dialog accepts a pasted proxy; Vietnamese complete (1612 of 1612 strings).

## Known issues
- **Phone profiles are flagged in two places.** scanbrowser.net reports "Software: anomaly" (time zone, fonts, touch and scrollbars were each ruled out); CreepJS reports one lie (`devicePixelRatio`: the window is drawn at 1, a true ratio would need a window 2.6 times larger) and marks the WebGL parameters suspicious (no public recording of a phone's WebGL exists). Use phone profiles where a desktop-grade WebGL is acceptable. Details: `docs/references/antidetect-generator-research.md`, `docs/specs/phone-identity-next.md`.
- `pointer: coarse` stays false on phone profiles (the engine ignores the switch); no checker tested flags it.
- Camoufox profiles: HTTPS-type proxies, extensions, bookmarks, cookie files, automation and the traffic panel are Chrome-only for now. Windows x64 only. Unpacking the engine takes a few minutes.
- The installer is not signed: Windows SmartScreen warns (More info → Run anyway).
- iOS profiles are not available.

## Upgrade notes
No data migration. Existing profiles stay Chrome profiles. A Camoufox profile keeps its Firefox data in `<profile>/firefox/`.
